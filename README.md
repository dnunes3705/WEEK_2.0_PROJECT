# Minimal EDA Project

This repository contains a minimal scaffold for exploratory data analysis (EDA).

Structure:
- data/: raw or small sample data files (do not commit large data)
- notebooks/: Jupyter notebooks for analysis
- src/: reusable python modules
- reports/: generated reports and figures

Quick start:
1. Create a virtual environment: `python -m venv .venv`
2. Activate it and install deps: `pip install -r requirements.txt`
3. Launch Jupyter Lab/Notebook and open `notebooks/analysis.ipynb`.
